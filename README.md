# Стол-переводчик RU ⇄ TR

Живой голосовой перевод в AirPods для русских и турок за одним столом.
Открываете ссылку, вводите имя и язык и говорите. Каждый слышит только перевод речи собеседников, говорящих на другом языке.

## Как это работает

```
Телефон (микрофон AirPods) ──PCM 24 кГц──► сервер ──► OpenAI Realtime ──► перевод ──► телефоны собеседников с другим языком
```

| Кто говорит | Модель OpenAI | Кто слышит |
|---|---|---|
| Турок | `gpt-realtime-translate` (специальная модель синхронного перевода, голос подстраивается под говорящего) | Только русские |
| Русский | `gpt-realtime-1.5` с инструкцией «синхронный переводчик» (translate-модель не умеет выводить турецкий) | Только турки |

- Сессия в OpenAI открывается, только когда за столом есть хотя бы один слушатель с другим языком. Если все говорят на одном языке, деньги не тратятся.
- Внизу экрана идут субтитры на вашем языке: перевод чужой речи и то, как распознали вас.
- «Порог» микрофона отсекает голоса соседей. Его можно настроить ползунком «Чувствительность».
- Выйти и зайти снова можно в любой момент. Имя и язык запоминаются на телефоне.

## Вариант 1. Быстрая проверка с Mac (10 минут)

Нужен Node.js 20+ ([nodejs.org](https://nodejs.org)).

```bash
cd masa-perevodchik
cp .env.example .env        # впишите свой OPENAI_API_KEY
npm install
npm start                   # сервер на http://localhost:3000
```

Телефонам нужна ссылка с HTTPS, без этого браузер не даст доступ к микрофону. Самый простой способ: временный туннель Cloudflare, без регистрации.

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:3000
```

Он покажет адрес вида `https://xxxx.trycloudflare.com`. Откройте его на телефоне и нажмите «Создать стол». Остальным отправьте ссылку или покажите QR-код: он открывается по нажатию на код стола.

## Вариант 2. Постоянный адрес на Render (бесплатно)

1. Загрузите эту папку в новый репозиторий на GitHub. Можно через сайт: «Add file → Upload files».
2. На [render.com](https://render.com) выберите New → Blueprint и укажите репозиторий. Файл `render.yaml` уже настроен.
3. Когда Render попросит, вставьте `OPENAI_API_KEY`.
4. Через пару минут появится адрес `https://masa-perevodchik.onrender.com`.

На бесплатном тарифе сервер засыпает после 15 минут без посетителей, и первый вход занимает около 30–50 секунд. Тариф Starter за $7 в месяц этого не делает.

Есть и `Dockerfile`: подойдёт любой хостинг, где поддерживаются WebSocket (Railway, Fly.io, свой VPS).

## Как пользоваться за столом

1. Все надевают AirPods. Рекомендуется режим «Прозрачность» или «Адаптивный»: так вы слышите и живую речь, и перевод.
2. Один человек создаёт стол и показывает QR-код, остальные сканируют его камерой.
3. Каждый вводит имя и язык и нажимает «Войти». Экран не блокируйте: если свернуть браузер, iPhone отключит микрофон.
4. Говорите обычными фразами с короткими паузами. Перевод приходит примерно через 1–3 секунды.
5. Если перевод цепляет соседей, уменьшите «Чувствительность» в ⚙︎. Если не слышит вас, увеличьте.
6. Если кто-то без наушников, включите в ⚙︎ «Я без наушников». Иначе его телефон будет переводить перевод.

## Стоимость (OpenAI, октябрь 2026)

- TR→RU: $0.034 за минуту потока. Поток идёт, пока турок сидит за столом и есть русский слушатель. Это примерно $2 в час на каждого турка.
- RU→TR: оплата по аудиотокенам ($32 за 1M на входе, $64 за 1M на выходе по прайсу gpt-realtime-2.1; у 1.5 сверьтесь с [прайсом](https://developers.openai.com/api/docs/pricing)). Платится только за реальную речь. Ориентировочно $1–3 в час на активно говорящего русского.
- Free-тариф OpenAI не подходит: нужен ключ с пополненным балансом. Рекомендую поставить месячный лимит в настройках биллинга.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `OPENAI_API_KEY` | — | Ключ OpenAI, обязательно |
| `OPENAI_REALTIME_MODEL` | `gpt-realtime-1.5` | Модель RU→TR. `gpt-realtime-2.1` переводит точнее, но с чуть большей задержкой |
| `VAD_SILENCE_MS` | `450` | Сколько молчания (мс) считать концом русской фразы. Меньше — быстрее, но фразы могут рваться |
| `MAX_SESSIONS` | `30` | Предел одновременных говорящих, защищает ключ от перерасхода |

## Ограничения прототипа

- Никакой авторизации: кто знает ссылку на стол, тот может войти. Код стола случайный, из 6 символов.
- Если два человека говорят одновременно, переводы звучат наложением.
- Русскоязычная сессия OpenAI длится до 60 минут, потом сервер сам переподключается при следующей фразе.

## Проверка

`npm test` проверяет маршрутизацию без OpenAI, на макете API. Проверяется, что перевод получает только слушатель с другим языком, что при выходе сессии закрываются и что повторный вход не создаёт дублей.
